# 筛选记忆
- 提问后将 messages 中筛选用户最近的几条消息 + 将记忆库中所有记忆按照 `name + description` 的格式发送给LLM, 让其筛选出前三个最匹配的记忆库进行加载
- 提取的记忆需要限制一下, 只提取前20000个字符

# 存储记忆
- 更新作用域和类型的分类
- 记忆库存储的类型一定是以下四种类型之一
    - 用户偏好
    - 过往反馈
    - 项目事实
    - 参考资料
- 作用域
    - 持久的: 以后每次对话都有可能用得上, 可以被记忆库存储
    - 当前任务: 不会被记忆库存储, 只有本次对话或这几分钟有用

# 更新记忆
- 记忆库最多 30 条记忆, 超过需要将其打包给 LLM 让其进行更新合并重复项、用新知识覆盖旧知识、重写文件
- 一般都在项目的最后, 在提取完记忆后面执行
- 执行完后需要对记忆库更新记忆索引值
