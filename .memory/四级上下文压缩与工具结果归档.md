name: 四级上下文压缩与工具结果归档
type: 项目事实
description: Compression 四级策略与 .compression_archive/tool-result/ 归档机制。
---

llm_chat.py 中的 Compression 采用四级上下文压缩策略，顺序为：工具结果归档截断 → 滑动窗口 → 动态驱逐 → LLM 总结，并配套超长错误恢复机制。被归档的工具结果写入 .compression_archive/tool-result/ 目录（例如 H:/AI Files/Harness-Agent/.compression_archive/tool-result/tool_result_<hash>.txt），归档文件带 [结果前缀] 形式的头部。项目使用 .compression_archive 目录存储压缩归档的工具结果，路径格式为 H:/AI Files/Harness-Agent/.compression_archive/tool-result/tool_result_<hash>.txt，压缩后的内容以 '[本地归档路径]' 和 '[结果前缀]' 形式呈现给模型。查看被截断/精简的工具结果时，可到该目录按 tool_result_<id>.txt 读取原文。
