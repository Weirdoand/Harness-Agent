name: 工具结果压缩归档
type: 参考资料
description: 长工具输出被压缩为 .compression_archive/tool-result/tool_result_<hash>.txt。
---

Harness-Agent 的长工具输出会被压缩归档到本地路径 H:/AI Files/Harness-Agent/.compression_archive/tool-result/，被压缩的 tool result 以 tool_result_<hash>.txt 形式存放（例如 tool_result_6d0f4061.txt），内容通常仅保留结果前缀。查看被截断/精简的工具结果时，可到该目录按 tool_result_<id>.txt 读取原文。
