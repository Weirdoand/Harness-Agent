name: 协作汇报口径与流程偏好
type: 用户偏好
description: 多 Agent 协作时的计划审批、总线通知、收口汇报格式与 worktree 要求。
---

在本项目（Harness-Agent 多 Agent 协作）中，用户/协调方期望的协作方式：1. 队友 Agent 通过 submit_plan 提交计划，需经审批后方可执行；空闲时用 idle_report 汇报。2. 审批结果需通过消息总线通知对应 Agent 才算放行。3. 任务收口汇报必须包含固定口径：文件清单、pytest 用例数与结果、受保护文件的 sha256 比对、worktree 干净度、分支提交哈希。4. 分解子任务需用 todo_write 维护阶段进度，长时间不更新会被系统提示。5. 认证相关任务（涉及 auth.py）必须使用独立 worktree（如 .worktrees/auth-refactor，分支 refactor/auth），不得在主工作树中修改认证代码；其他任务（如 config 抽取）可在主工作树原地进行，但禁止触碰 .worktrees/ 和 auth.py。
