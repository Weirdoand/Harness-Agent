---
name: todo_write 阶段步骤更新约束
type: 参考资料
description: 连续 3 次及以上未更新任务阶段步骤时，系统会提示调用 todo_write 更新子任务状态与进展。
---

在该 harness 中，当助手连续 3 次及以上未更新任务阶段步骤时，系统会注入提示：「你已连续 3 次及以上未更新任务阶段步骤，请调用 todo_write 工具更新当前分解的子任务状态与进展。」说明 todo_write 是用于维护子任务状态与进展的工具，长时间不更新会触发该提醒。长任务执行过程中应主动调用 todo_write 更新子任务状态（如 [x] 已完成、[-] 进行中），避免触发该提醒。
